# Misión del Proyecto ORSEE

**ORSEE (Online Recruitment System for Economic Experiments)** es una plataforma web de código abierto diseñada específicamente para la organización, gestión y reclutamiento de participantes en experimentos económicos y de ciencias del comportamiento.

## Objetivos Clave

1. **Gestión de Participantes**: Mantener una base de datos segura y organizada de voluntarios y participantes para estudios científicos.
2. **Reclutamiento Eficiente**: Automatizar la selección y envío de invitaciones/recordatorios a perfiles específicos de participantes que cumplan con criterios predefinidos para los experimentos.
3. **Gestión de Calendario y Laboratorio**: Facilitar la reserva de espacios físicos (laboratorios), la programación de sesiones y el control de asistencia.
4. **Cumplimiento y Privacidad**: Asegurar que el proceso de reclutamiento respete las normativas de protección de datos (como el RGPD) y los requisitos de comités éticos institucionales.
